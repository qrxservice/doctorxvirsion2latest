# UX REQUIREMENTS

The medicine entry process should feel fast.

Desired flow:

1. Doctor clicks medicine input.
2. Types medicine name.
3. Existing suggestions appear.
4. Doctor selects medicine.
5. Selects dose.
6. Selects timing.
7. Selects duration.
8. Clicks Add Medicine.
9. Immediately starts typing the next medicine.

Avoid unnecessary popups.

Avoid multi-step dialogs.

Avoid requiring the doctor to leave the prescription screen.
